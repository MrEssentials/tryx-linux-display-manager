# TRYX Linux Display Manager

An unofficial Linux display manager for compatible TRYX Turris LCD displays.

## Features

- Upload pictures and videos
- Exact 1280 x 720 LCD preview
- Crop, zoom, rotate, and reposition media
- Mixed picture and video shuffle
- Adjustable picture display duration
- Source-matched video frame rates
- Continuous display playback
- Optional donation support

## Requirements

- Linux Mint or Ubuntu-based Linux distribution
- Python 3
- PySide6
- PyUSB
- FFmpeg
- Compatible TRYX display

## Installation

Run:

    chmod +x install.sh
    ./install.sh

Launch the application:

    ~/.local/bin/tryx-gui

## Compatibility

Developed and tested with a TRYX Turris display using USB device ID:

    391a:2011

Other TRYX models have not yet been confirmed.
